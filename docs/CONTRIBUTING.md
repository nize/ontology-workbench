# Contributing

## Branching
- `main`: protected
- `feat/*`, `fix/*`, `chore/*`

## Commits
Conventional Commits (e.g., `feat(frontend): add tree lazy-load`)

## PRs
- Reference ticket id (e.g., FE-004)
- Include screenshots for FE changes
- CI must pass (lint, typecheck, tests)

## Testing
- Unit tests for helpers and adapters
- Integration tests for API handlers (mock GraphDB when needed)
