# BE-006 — Search Metadata Filters & Facets

## Goal
Let search results be narrowed by entity metadata, not only by text.

## Scope
- Index per entity: namespace, `rdfs:isDefinedBy`, property kind, direct class (individuals), `owl:deprecated`
- `GET /search` accepts `type` (multi), `definedBy`, `namespace`, `propertyKind`, `instanceOf`, `deprecated`, `fields`, `facets`
- Facet counts per filter value (disjunctive: a facet ignores its own selection)
- Empty `q` with filters/facets browses by label

## Acceptance
- Existing `q`/`type`/`limit`/`offset` requests behave as before
- Filters combine with AND across filters, OR within a filter
