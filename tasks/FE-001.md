# FE-001 — App Shell & 3-Pane Layout

## Goal
Responsive 3-pane layout with collapsible left/right, dark mode.

## Scope
- Next.js (App Router), Tailwind, shadcn/ui, Lucide, TanStack Query
- Grid areas: nav | main | details
- Keyboard: `[` collapse left, `]` collapse right, `/` focus search, `Cmd/Ctrl+K` global search
- Persist pane state (URL + localStorage), dark mode toggle

## Acceptance
- ≥1280px: 3 panes; 1024–1279px: details collapsed by default; <1024px: stacked
- Axe-core basic checks pass
- URL reflects `?pane=diagram|search&details=on|off`
