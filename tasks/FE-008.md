# FE-008 — Advanced Search Pane

## Goal
Search with metadata filters in the center pane (`pane=search`).

## Scope
- Query input, facet sidebar with counts, active-filter chips, paged results
- Query, filters and page live in the URL (shareable)
- Header search: filter button and "see all results" footer / Enter open the pane with the query

## Acceptance
- Pasting an advanced-search link restores query, filters and page
- Selecting a result opens it in the diagram with details
