# FE-002 — Type Hierarchy Navigator

## Goal
Virtualized, collapsible tree with lazy loading.

## Scope
- Filter box (client-side filter)
- Virtualized list
- Secondary-parent badge “+N”
- Context menu: Open in center / Show details

## API
GET `/types/tree?root=<iri>&depth=<int>&workspace=main`

## Acceptance
- Lazy-load per expand, cached
- Selecting node syncs center + details
- Filter preserves expansion where possible
