# FE-003 — Global Search

## Goal
Fast search with ranked results in center pane.

## Scope
- Header input (Cmd/Ctrl+K)
- Debounced requests, highlight matches
- Type chips, breadcrumbs

## API
GET `/search?q=&type=&limit=&offset=`

## Acceptance
- <200ms roundtrip local
- Keyboard nav ↑/↓ Enter
- Clicking result selects and opens details
